New Component Features

1. Date Range Component:

  • Default range of 4 days from today
  • Visual range highlighting in calendar (red start/end, light red between)
  • Return date cannot be before departure date
  • Max range of 80 days (configurable)
  • Calendar opens to current selection month
  • Fill appearance with floating label

2. Multiline Select Dropdown (Regions):

  • Options display region name and description in multiline format
  • Line separator between options
  • Only region name displayed in trigger (not description)
  • Selected option shown bold with checkmark on right
  • Hover effect on options
  • Fill appearance with floating label

3. Split Select Dropdown (Coverage):

  • Options display left (coverage) and right (price) sections
  • Both sections displayed in trigger when selected
  • Selected option shown bold with checkmark on right
  • Hover effect on options
  • Fill appearance with floating label

4. Select Dropdown (Cover Type):

  • Non-editable dropdown (user can't type)
  • Default value pre-selected (Individual)
  • Single selection only
  • Selected option shown bold with checkmark
  • Hover effect on options
  • Fill appearance with floating label

5. Autocomplete Input (Nationality):

  • User can filter by typing OR select from dropdown
  • Can enter custom value without dropdown selection
  • Starts empty (no default value)
  • Single selection
  • Selected option bold with checkmark when dropdown reopened
  • Hover effect on options
  • Fill appearance with floating label

6. Multi-Select Autocomplete (Destinations & Activities):

  • Multiple selections as chips
  • Search and filter functionality
  • Grouped options (Destinations)
  • Max selection limit (Activities - 3 max)
  • Fill appearance with floating label
